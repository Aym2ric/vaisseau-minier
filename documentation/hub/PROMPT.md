# Mission Claude Code
Implémente le hub du vaisseau-mère dans le projet Godot existant, en suivant SPEC.md, TECHNIQUE.md, TESTS.md et maquettes/. Lis d'abord le GDD V5 et features/24-hub.md, 27-sauvegarde.md, 30-technique.md. Inspecte project.godot, scènes, autoloads, sauvegardes et tests avant de modifier quoi que ce soit. Réutilise les services existants ; les noms proposés ne sont pas des obligations. Ne crée pas de deuxième système de progression ou de sauvegarde. Ne réintroduis aucun outil de minage. Ne modifie pas les mécaniques de combat ou d'expédition hors intégration nécessaire. Présente un plan et les écarts détectés, puis implémente par tranches testables. Commence par Navigation + Hangar + lancement réel, ensuite Recherche, Entrepôt, Archives, Paramètres. Ne simule pas un succès de sauvegarde ou de lancement. Les données manquantes doivent être signalées et les actions correspondantes désactivées. Les exemples graphiques ne sont pas des données d'équilibrage. Termine avec les fichiers modifiés, tests réellement exécutés, résultats et limites.
